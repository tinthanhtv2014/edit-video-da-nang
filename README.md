# Klip Studio — Free Video Editor in Your Browser

**Use it now, no installation:** https://klip-studio.tinthanhtv2014.workers.dev
(Mirror: https://tinthanhtv2014.github.io/edit-video-da-nang/)

Klip Studio is a free video editor that runs entirely in your browser. Drop in a clip and start editing — your videos are processed locally on your device and are **never uploaded to any server**. No sign-up, no watermark, completely free.

## Features

- Multi-clip timeline with independent audio tracks — split, trim, reorder, transitions
- Subtitles per sentence with karaoke word highlighting, SRT import/export
- AI auto-captions, AI background removal, AI face blur (experimental)
- Voice-over recording, automatic silence cutting, boomerang, slideshow from photos
- Filters, color grades, 8 built-in themes + your own saved themes
- Text, sticker and image overlays with masks, blend modes and keyframes
- Music track with auto-ducking, volume keyframes, echo and voice effects
- Export up to 1920px — MP4 (preferred) / WebM, plus GIF and WAV export
- Projects saved in your browser (IndexedDB), PNG snapshots

## Desktop apps (free)

- **Windows:** portable `.exe` — [Download](https://github.com/tinthanhtv2014/edit-video-da-nang/releases/latest/download/KlipStudio-Windows.exe) — just run it. Windows may warn because the app is unsigned: click *More info → Run anyway*.
- **Ubuntu:** `.deb` — [Download](https://github.com/tinthanhtv2014/edit-video-da-nang/releases/latest/download/KlipStudio-Ubuntu.deb) — install like a normal app (`sudo apt install ./KlipStudio-Ubuntu.deb`).

Desktop extras: native save dialogs for exports, projects as real `.klip` files, "Open with Klip Studio" for video files, export progress on the taskbar, and update notifications.

All versions: [GitHub Releases](https://github.com/tinthanhtv2014/edit-video-da-nang/releases)

## How it works

The whole editor is a single self-contained web page — this repository is exactly what gets served (GitHub Pages + Cloudflare). Media never leaves the visitor's device: decoding, editing preview and export all happen client-side.
